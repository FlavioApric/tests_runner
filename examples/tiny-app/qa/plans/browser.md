## Sharded (2 shards)

Each shard writes a blob report (QA_BLOB=1); merge them into one HTML report and one junit file:

```bash
QA_BLOB=1 npx playwright test -c playwright.config.mjs --shard=1/2
QA_BLOB=1 npx playwright test -c playwright.config.mjs --shard=2/2
npx playwright merge-reports --reporter=html,junit ./blob-report
```

On the cloud fleet every shard is its own unit (`<step>-i-of-N`), and the blob reports come back in the unit results.
